# Distribution overview

The DAFC distribution includes the routing package, offline example,
configuration interfaces and public statistical inputs. Browser, Android and
model workflows use the resources documented in [RESOURCES.md](docs/RESOURCES.md).

`PUBLIC_MANIFEST.json` defines the reviewed source export. See
[release notes](docs/RELEASE_NOTES.md), [validation](docs/VALIDATION.md) and
[third-party notices](THIRD_PARTY.md) for release contents and verification.
