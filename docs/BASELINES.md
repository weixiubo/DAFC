# Regression baseline

The reference public revision is `8b0eae11468195ce86ccb33fea980334c72ac2d6`.
Its 22 tests and five subtests are represented in the current suite.
`TEST_MIGRATION.json` maps imports and state ownership;
`tests/reference/MANIFEST.json` identifies the original implementation inputs
used for deterministic comparisons.

[VALIDATION.md](VALIDATION.md) describes controller, selector and atomic-trial
comparisons. [MIGRATION.md](MIGRATION.md) documents current entrypoints and
module ownership. `MODULE_MIGRATION.json` records the earlier pilot-to-package
mapping.
